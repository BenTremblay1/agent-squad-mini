# CertMatrix — Recommended landing page structure (section order + rationale)

Audience: office managers / safety coordinators at non‑union construction subs.
Primary jobs-to-be-done:
- “GC asked for proof of training / training matrix; I need it fast.”
- “Keep expirations from becoming jobsite emergencies.”

## 0) Global principle
Pick **one primary conversion** per traffic type (or route to separate variants):
- **Search (high intent):** “Generate PDF / Start / Book setup”
- **Facebook (cold):** “Book free setup call”
If we keep the template, treat it as **secondary** unless we intentionally want low-intent lead capture.

---

## Variant A: Google Search landing (high intent)
### 1) Hero (deliverable-first)
**Headline:** “Generate a GC‑Ready Training Matrix PDF in 30 Seconds”
- 3 bullets that match search intent:
  - 1‑click PDF export (GC-ready)
  - Expiration alerts (60/30/7 days)
  - Dashboard (compliant / expiring / overdue)
**Primary CTA:** “Generate My Matrix” or “Start in 60 Seconds”
**Secondary CTA:** “Book 15‑min setup call”
**Trust microcopy:** “No credit card” / “Import your spreadsheet”

Why: Search visitors want the output. Booking a call can be step 2.

### 2) “GC Email” problem block (specific scenario)
A short narrative card:
- “Send your training matrix by EOD”
- “Stop digging through tabs + email chains”

Why: Converts vague search intent into an emotionally vivid moment.

### 3) Product proof (show the PDF)
- Screenshot/mock of exported PDF preview + “What the GC expects to see” callouts
- Optional: “Download sample PDF” (gated or ungated)

Why: Proof beats promises; reduces risk.

### 4) How it works (3 steps)
1) Import spreadsheet/CSV (or paste roster)
2) Set cert types + renewal periods
3) Export PDF + get alerts

Why: Replaces uncertainty with a simple path.

### 5) Benefits (tie to outcomes)
- Win prequal / audits: “proof of training ready in seconds”
- Prevent gate issues: “no one turns up without valid credentials”
- Reduce admin: “single source of truth; version control”

Why: Converts features to business value.

### 6) Pricing (keep it simple)
- Consider anchoring to “cost of one shutdown day” or “one missed cert”
- Add “Founders pricing” if real

Why: Search traffic expects pricing clarity.

### 7) FAQ (objections)
Put the highest-friction questions first (importing, cert coverage, alerts).

### 8) Bottom CTA (repeat primary)
Keep the primary CTA consistent (“Generate / Start”).

## Variant B: Facebook cold traffic landing (trust + hand-holding)
### 1) Hero (pain + reassurance)
**Headline:** “Stop scrambling for proof of training.”
**Subhead:** “CertMatrix exports a GC-ready training matrix PDF in 30 seconds + alerts you before cards expire.”
**Primary CTA:** “Book free setup call”
**Secondary CTA:** “Get the free template”

Why: Cold visitors need a guided next step.

### 2) “Sound familiar?” pain points (keep, but make more concrete)
Current page does this well. Tighten copy to:
- “GC wants the matrix tomorrow”
- “Find out OSHA 30 expired at the gate”
- “Spreadsheet version-control hell”

### 3) Credibility / trust block (add real proof)
Right now you have stats (“100% audit pass rate”) that feel made up.
Replace with one of:
- Early-access beta positioning: “Built with 3 subcontractors in NYC/LA…” (if true)
- Compliance framing without fake metrics: “Designed around what GCs ask for”
- Logos/testimonials (only if real)

Why: Fake-sounding numbers hurt conversion.

### 4) Demo: show the matrix + alerts
Keep the UI mock, but add:
- “This is what the GC gets” + “This is what you track daily”

### 5) “We’ll set it up with you” (reduce effort)
- Import your spreadsheet
- Confirm cert list
- Set alert schedule

Why: Overcomes “I don’t have time to set up another tool.”

### 6) Pricing (optional / downplay)
If FB is purely lead-gen for calls, you can move pricing lower or use “starting at $49/mo”.

### 7) FAQ

### 8) Bottom CTA
Repeat “Book free setup call” with a short reassurance line.

---

## Cross-page copy fixes (quick wins)
1) **Remove emojis from pain point cards** (or keep minimal). Construction folks won’t care, but emojis can cheapen perceived seriousness.
2) **Clarify ‘GC portal access’** (in pricing). If it’s not real yet, remove. Unmet expectations kill trust.
3) Replace “YOUR_PIXEL_ID_HERE” / placeholder signals before sending traffic.
4) Make the template CTA explicit:
   - “Free Excel template (basic tracking). CertMatrix = alerts + 1‑click PDFs + less admin.”

## Open question for Ben (affects structure)
- Do we want the landing page to **sell self-serve** (trial/signup) or to **sell a call**? We can optimize either, but mixing both as equal primaries usually lowers conversion.
