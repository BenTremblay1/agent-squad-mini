# CertMatrix — CTA experiments to test

Goal: raise conversion by matching CTA to intent + reducing perceived effort.

## Test 1: Call-first vs Self-serve-first (by traffic source)
- **A (Facebook):** Primary = “Book Free 15‑Min Setup Call”
- **B (Google):** Primary = “Generate My Training Matrix” / “Start in 60 Seconds”

Success metric: lead rate (FB) vs start rate (Search) and downstream activation.

## Test 2: “Generate sample PDF” as a low-friction primary CTA (Search)
- **A:** “Book Free Setup Call”
- **B:** “Generate a Sample GC‑Ready PDF” (no login or email after click)
- **C:** “Upload Spreadsheet → Get PDF Preview” (light gating)

Why: gives immediate proof; reduces call aversion.

## Test 3: Template CTA positioning (lead quality vs volume)
- **A:** Hero secondary CTA = “Get Free Template”
- **B:** Template moved below fold; hero has only 1 CTA
- **C:** Template becomes a “text link” under primary CTA (de-emphasized)

Why: the template can siphon high-intent buyers away from the main conversion.

## Test 4: Risk reversal / effort reduction microcopy
Swap CTA subtext beneath the button:
- “No credit card • Import your spreadsheet • 15 minutes”
vs
- “We’ll set it up with you • You leave with a PDF you can send today”

Why: speaks directly to the office manager’s time constraint.

## Test 5: CTA wording anchored to the GC moment
Try button labels:
- “Send the GC a Matrix”
- “Export My GC‑Ready PDF”
- “Get Audit‑Ready”

Why: concrete output beats abstract “Get started.”

---

## Implementation note
If you can’t run true split tests yet, you can still rotate variants weekly and track:
- CTA click-through
- lead form completion
- call bookings
- time-on-page / scroll depth
