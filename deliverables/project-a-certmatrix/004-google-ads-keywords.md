# CertMatrix — Google Ads keywords + structure

Date: 2026-02-02
Owner: Hawkeye

## Assumptions (so Ben can sanity-check fast)
- Target: US-based subcontractors (10–100 employees), non-union; buyer = office manager / safety / ops.
- Primary CTA: **Generate a GC-ready training matrix PDF** / “See who’s expiring / overdue”.
- Landing page can support 2 core headline variants:
  1) **Stop scrambling for proof of training. Generate a GC-ready training matrix PDF in 30 seconds.**
  2) **Know who’s trained, who’s overdue, and what’s about to expire.**

If you decide to go **NYC SST / LL196** specific, we should split campaigns by geo + cert type.

## Campaign structure (recommended)

### Campaign 1 — High intent (Search)
- Bidding: Max Conversions / tCPA once you have volume; start w/ Max Clicks + CPC cap.
- Locations: Start tight (your initial target states/cities).
- Ad schedule: Business hours first, then expand.

Ad groups (4–5):
1) **Training Matrix (core)**
2) **Proof of Training / Audit Ready**
3) **Cert Tracking / Expiration Alerts**
4) **Training Register / Spreadsheet Template seekers**
5) *(optional)* **Subcontractor Compliance / Prequal**
